# 视频重定向教师：结论与经验（收尾）

本轮目标是把「人 + 实拍 MicroDuck」的韩国鸭舞，做成**看起来像右边那只真鸭子**的教师。
结论：**现有 2D 跟踪 + 关节启发式 / 弱透视 IK，都还不够像。这个方向先停。**

## 试过什么

1. **旧 CoTracker 14 点 + VelStand overlay**  
   裁切吃进 B 站标题，脚点落在字幕上，动作幅度只有 ~0.12 rad。看起来像站着轻微晃。

2. **鸭子步（人-only 视频）**  
   YOLO 人体 → 髋关节启发式，DeepMimic 能训稳，但是**人的步态，不是 MicroDuck 形态**。

3. **紧裁剪实拍鸭 + 喙/镜头/脚外观点 + 解析重定向（含 root yaw）**  
   能做出转头、转体、下蹲量级（peak ~1 rad，root yaw ~90°），比旧教师更接近片里的「转身」。  
   但脚点经常漂到键盘，头点会和显示器糊在一起，姿态仍明显不像。

4. **同一套点 + MuJoCo 前向弱透视 IK**  
   重投影仍 ~100 px，IK 会过拟合噪声脚点，比解析法更抖、更不像。

## 经验

- **同形态实拍 ≠ 人体 YOLO。** 要从鸭子像素反解 14 关节 + 根姿态，不能先跟人体再加偏移。
- **查询点和裁切错了，后面全错。** 字幕、键盘、显示器都会被当成脚/头。
- **MicroDuck 没有独立腰。** 片里的拧腰只能用对侧髋 yaw / 同侧髋 roll 近似；90° 转身是 **root yaw**，不是 14 维关节。
- **VelStand overlay 会和舞蹈打架**，也不能转身子。要看教师像不像，应直接回放重建的 `qpos`。
- **5 个噪声 2D 点不够做机器人姿态。** 文献里能用的是标定相机 + 轮廓/渲染对比（RoboPose 一类），不是再调一套启发式。
- 若以后再做：优先真机编码器 / mocap / 多机位；或对紧裁剪鸭子做 silhouette render-and-compare。不要再加第三套 2D 点规则。
